# Appearance panel proposal

Status: approved and implemented. The palette hover panel replaces the old selector.

- Put a palette icon after Refresh. Hover opens the panel; keyboard activation and touch also open it.
- Use a three-choice segmented control: DAY, NIGHT, SYSTEM. This changes light and dark appearance.
- Keep Theme as a separate list below. It contains ChatGPT and the Codex preset group, filtered to native variants supported by the current appearance.
- Remember appearance and each appearance’s selected theme separately. Preserve existing light/dark/system choices when changing the control.
- System follows operating-system appearance. ChatGPT is the default palette. Theme changes preserve the layout.
- Keep the panel open while the pointer moves into it. Escape, outside click, or leaving closes it.
