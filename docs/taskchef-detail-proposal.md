# Chat details proposal

Status: proposed, awaiting design review.

- Keep the chat title, project, queue label, and Open in Codex action at the top.
- Keep Mark Done only when the existing rules allow it. Put Copy chat ID and archive guidance in the action menu.
- Give the latest saved reply excerpt the largest area. Render Markdown and supported images with the existing image access rules.
- Show PR title and number as a link, PR state, CI, work duration, next schedule time, and direct subagents (all chat history). Hide missing rows.
- Place these rows beside the reply in wide views and above it in narrow views.
- Collapse technical details by default: IDs, path, queue reason, and source records.
- Retain the current saved reply scope; this proposal does not add a full conversation history reader.
